# Vertex AI Gen AI Evaluation Service & Production Monitoring

This package integrates the **Vertex AI Gen AI Evaluation Service (`vertexai.evaluation`)** for cloud-scale benchmarking, LLM-as-a-judge rubrics, and continuous production monitoring.

It forms **Tier 2** of the evaluation architecture (complemented by Tier 1 ADK Built-in Evaluation in `evals/adk/`).

## Architecture & Capabilities

1. **LLM-as-a-Judge Rubrics (`rubrics.py`)**:
   - `groundedness_score`: Evaluates whether all factual statements (prices, ingredients, return windows) are supported by retrieved catalog and knowledge passages.
   - `persona_quality_score`: Evaluates French consultative dialogue, empathy toward skin conditions, non-pushy tone, and clarification before prescribing routines.
   - `safety_refusal_score`: Asserts clean redirection on out-of-scope trivia and firm defense against social engineering (e.g. employee discount leaks).
   - `claim_compliance_score`: Ensures claims are triaged accurately without promising unapproved refunds.

2. **Cloud-Scale Benchmarking (`run_vertex_eval.py`)**:
   - Runs `vertexai.evaluation.EvalTask` over evaluation datasets.
   - Tracks benchmark runs in **Vertex AI Experiments** (`beauty-advisor-benchmark`) in the Google Cloud Console.
   - Produces radar comparison charts and scorecards across models (e.g. `gemini-2.5-flash` vs `gemini-3.8-flash`).

3. **Production Monitoring (`monitor_production.py`)**:
   - Cloud Run logs customer interactions to **BigQuery** via OpenTelemetry / PubSub.
   - Samples production traces over a 24-hour window and computes drift scorecards.
   - Triggers alerts if groundedness or safety falls below the configured threshold.

## Running Evaluations

### 1. Cloud Benchmark against ADK Traces
Takes the latest traces generated by `evals/adk/` and evaluates them with Vertex AI:

```bash
uv run --env-file copilot/.env python -m evals.vertex.run_vertex_eval --threshold 4.0
```

For offline local testing without making GCP calls:
```bash
uv run python -m evals.vertex.run_vertex_eval --mock
```

### 2. Continuous Production Monitoring from BigQuery
Samples live traces from the production BigQuery dataset and scores policy adherence:

```bash
uv run --env-file copilot/.env python -m evals.vertex.monitor_production \
  --dataset-id beauty_copilot \
  --table-id agent_turns \
  --sample-size 50
```

For local dry-runs:
```bash
uv run python -m evals.vertex.monitor_production --mock
```

## Viewing Results in Google Cloud Console
Benchmark runs and production monitor runs are logged directly to **Vertex AI Experiments**:
- Navigate to **Google Cloud Console → Vertex AI → Experiments**.
- Select the `beauty-advisor-benchmark` or `beauty-advisor-prod-monitoring` experiment.
- Inspect radar charts, mean score distributions, and individual response rationale.
