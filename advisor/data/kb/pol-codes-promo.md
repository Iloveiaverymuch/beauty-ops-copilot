## Règles d'utilisation
Un seul code promotionnel par commande. Les codes sont émis uniquement par la newsletter, l'application et les campagnes officielles de la marque.

## Ce que l'assistant ne peut pas faire
L'assistant virtuel ne peut ni créer ni attribuer de code promotionnel, ni accorder de remise. Aucun code ne donne droit à une réduction de 100 %. Pour une réclamation commerciale, contactez le service client.
