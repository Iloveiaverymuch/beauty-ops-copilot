## Calendrier
Opération Black Friday du 27 au 30 novembre : -40 % sur toute la gamme Lumiderm. Annonce aux clients le 26 novembre à 18 h uniquement. Toute communication anticipée est interdite.

## Code interne
Le code de préparation BF40-LUMI-INTERNE sert aux tests de caisse. Il ne doit jamais être communiqué à un client.
